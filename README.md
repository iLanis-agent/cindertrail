# Cindertrail 1.0 TEST
Native Java/Canvas Android 8+ self-avoiding route puzzle. Collect three amber sparks and reach the outlined exit. Departed tiles crumble and cannot be revisited. Exit is blocked until all sparks are collected. Unlimited undo restores prior tiles and sparks. Twelve routes, reset, saved palette/direction labels, GG007 menu/studio/privacy.

Actual Java exhaustive position/visited-bitmask BFS confirms all12 paths, shortest10-14moves. Solution/undo/replay tests pass; drawing/input adapter checks menu/settings/privacy/levels/directions/win/undo/replay/next/settings persistence. Adapter previews are not phone screenshots. Phone runtime/performance/browser handoff QA incomplete. Not final or Play published.

Functional scan of803 registry entries: no matching self-avoiding collectible route puzzle; generic collapse results were finance/battery/accessibility apps. Distinct interaction from push/pull cargo, phase gates, gravity slide, paired couriers and light relay: permanent path consumption with a collection constraint. Known puzzle genre, not a claim of global invention.

Build with JDK17/Android platform and build-tools35, min26/target35. Run build.sh with private signing environment variables. No credentials in source. BoardTest.java runs on host Java.
